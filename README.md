# 抓大眼

克苏鲁的小点心～

一款克系恐怖像素风的堆叠三消小游戏：献祭盘里堆满了眼球、触手、蜡烛和小雕像，你坐在桌子近端抓供品，对面坐着克苏鲁本人——盘里的东西本来都是给他备的点心。

- 只能抓最上层没被压住的供品，抓进 7 格槽，3 个一样的自动献祭消除
- 槽满 7 格还没消掉判负，盘子抓空判胜
- 他会伸触手捣乱：卷走你快凑齐的供品、横扫祭盘、或者整条压住盘面不让你玩
- 点他的触手会 Q 弹缩回；压盘的时候，捏住触手往旁边拖开它

完整构思与制作规格见 [CONCEPT.md](CONCEPT.md)（玩法数值、视觉定调、机位、触手互动、验收清单都在里面）。

> 灵感只借「怪物对手 + 满墙眼睛」的氛围，玩法与棋类无关，骨架是堆叠三消。
