# 抓大眼

克苏鲁的小点心～

一款克系恐怖像素风的堆叠三消小游戏：残破神殿的祭台上摆着一只圆形石供品盘，盘里堆满了有体积的眼球、触手、蜡烛和小雕像，你坐在桌子近端抓供品，对面坐着克苏鲁本人——盘里的东西本来都是给他备的点心。

- 只能抓最上层没被压住的供品，抓进槽，3 个一样的自动献祭消除
- 槽满还没消掉判负，盘子抓空判胜
- 他会伸触手捣乱：卷走你快凑齐的那一对、塞回盘底被压住的地方；或者整条压住盘面不让你玩；第四夜起还会用舌头把你槽里的供品**调包**
- 点他的触手会 Q 弹缩回；压盘的时候，捏住触手往旁边拖开它（拖不够远会弹回来），或者连戳 4 下把它戳跑

## 五个祭夜

每一夜的盘子、规则和祂的脾气都不一样，重复感藏在深处：

| 夜 | 盘面 | 规矩 | 恐怖点 |
| --- | --- | --- | --- |
| 一 · 七眼祭盘 | 63 件 / 7 种 / 3 层 / 槽 7 | 经典盘 | 祂只是看着，偶尔伸手 |
| 二 · 腐眼宴 | 72 件 / 8 种 / 3 层 / 槽 7 | 混入腐化之眼：献祭它不祥（San −6），它的瞳孔会一直转着看你 | 供品不太新鲜，有几只还在看 |
| 三 · 沉没祭盘 | 84 件 / 7 种 / 3 层 / **槽 6** | 潮水按时涨落，被淹的供品抓不得，要等退潮的窗口 | 水下有影子游过，淹掉的供品会自己动 |
| 四 · 血月当空 | 84 件 / 7 种 / **4 层** / 槽 7 | 每献祭 3 组血月升一分：捣乱更勤、舌头开始调包；血月满时**祂会站起来**。点血月让它垂眼一会儿，代价 San −6 | 血月里有一只慢慢睁开的眼睛 |
| 五 · 祂的凝视 | 96 件 / 8 种 / 4 层 / **槽 8** | 祂周期性盯死一种供品：眼墙先转向预告，被盯住的抓不得（硬抓被咬 San −15）；多献祭能让祂移开视线 | 抓到只剩 9 件时灯会灭，祂凑得越来越近 |

所有夜共通的恐怖层：深渊底噪与心跳（San 越低越急）、屏幕边缘的低语、供品偶尔蠕动、以及低概率的「凝视惊吓」——祂会突然凑近。

调试与体验：URL 加 `?lv=N` 直接进第 N 夜（不影响存档）；`?2d` 回 2D 克苏鲁，`?proc` 回手捏 3D 模型。

完整构思与制作规格见 [CONCEPT.md](CONCEPT.md)（玩法数值、视觉定调、机位、触手互动、验收清单都在里面）。

> 灵感只借「怪物对手 + 满墙眼睛」的氛围，玩法与棋类无关，骨架是堆叠三消。

## 怎么玩

纯静态网页，不需要构建。直接用浏览器打开 `index.html`，或者在仓库目录里起一个静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

桌面端用鼠标，手机端用手指，都能拖触手。音效是 WebAudio 实时合成的（没有任何音频文件），首次点击「开始献祭」后开始出声，右下 ♪ 可静音。

## 小细节

- 三种眼球不只靠瞳色区分：红瞳是圆瞳加重血丝，蓝瞳是三个小瞳孔，绿瞳是环形瞳，金色猫眼是竖瞳。San 低、画面发红时也认得出来。
- 开局用倒推法生成：先随机一条合法的抓取顺序，再按顺序分配类型，保证至少有一条通关路线。洗牌时会先补齐槽里的残组，再重排其余。每夜的布局都通过「可抓空 + 同层不重叠 + 不越出盘沿」的自动校验（`node test/logic.test.mjs`）。
- 被卷走的供品会被塞回「下层」——找空着且正被别的供品压住的位置，要绕路才能拿回来。
- 触手捣乱发生后，撤销只能退回到捣乱之后，不能撤回捣乱本身；三消之后也不能撤回。
- San 只做氛围反馈：越低，瞳孔越红、暗角和噪点越重、画面越抖、心跳越急，不影响胜负。
- 整个画面在低分辨率画布上渲染再整数放大，所以透视下的供品、触手也是真像素。点选按供品贴图的像素轮廓判定（透明处不算），透视下不会点偏。
- 克苏鲁身后左右各四条粗触手，两条最粗的手臂沿祭台两侧爬出屏幕；祭台周围的地面积着浅浅的水洼，偶尔荡开涟漪。

## 文件结构

```
index.html          页面骨架与界面
css/style.css       祭坛面板、扫描线、闪烁
js/util.js          随机数、几何小工具
js/projection.js    桌面透视机位（投影 / 反投影）
js/monster3d.js     three.js 3D 克苏鲁（与游戏同一相机、低清无抗锯齿渲染 + 像素描边）
js/vendor/three.min.js  three.js r149（MIT）
js/sprites.js       24×24 有体积的像素供品（球面打光、程序化点阵），含腐化之眼
js/levels.js        五个祭夜：布局、槽位、捣乱配方、所属仪式
js/board.js         布局摆放、压住判定、可解的类型分配、塞回下层
js/game.js          槽位、三消、撤销、洗牌、San、捣乱节奏、胜负
js/rites.js         各夜仪式（腐眼 / 潮汐 / 血月 / 凝视锁定 / 黑暗终局）+ 低语、蠕动、凝视惊吓
js/audio.js         WebAudio 程序化音效：底噪、心跳、湿黏抓取、献祭钟、惊吓弦音
js/monster.js       克苏鲁本体、眼墙、三种触手捣乱与戳 / 拖交互
js/render.js        神殿祭台、圆形石供品盘、供品、石杯槽位、水面、血月、录像带噪点
js/main.js          画布缩放、输入、主循环、存档
test/logic.test.mjs 布局可解性与仪式状态机的自动测试
```
